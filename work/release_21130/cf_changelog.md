## 三节点通用：实体透明材质不再遮挡水面 / 半透明层序稳定

同一 Bedrock 材质此前由三套构造各自重建渲染状态。26.1 上 **blend 与发光叠加层既没有
alpha 裁剪、又按默认写深度**：贴图里完全透明的像素仍写入深度，随后原版透明层合成
（`post/transparency`）按深度排序时把水判到背景之后——表现为**透过幻翼翅膀 /
监守者发光片的透明部分看不到水**；同一模型的多层半透明又因深度口径不一致出现
**层序翻转，近距离看起来像 z 冲突闪烁**。

- 统一实体通道的 alpha 裁剪与深度写口径（ADR-0042）：
  - 非不透明实体 pass 一律 `ALPHA_CUTOUT=0.1`（与原版各实体管线一致）；
  - 发光半透明层不写深度（与原版 `ENTITY_TRANSLUCENT_EMISSIVE` 一致）；
  - 半透明仍写深度（与原版 `ENTITY_TRANSLUCENT` 一致），层间遮挡不再依赖绘制顺序。
- 1.20.1 / 1.21.1 补齐此前被丢弃的组合：`entity_nocull` 不再被强制开启背面剔除，
  ADDITIVE 材质不再退化成 alpha 混合，发光半透明材质不再写深度。
- 实体 RenderType 开启 AFFECTS_OUTLINE（与原版实体类型一致，发光描边可用）。

观感变化：透明区域不再吃水面；半透明部件的重叠顺序稳定，不再随视角闪动。
